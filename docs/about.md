# Мобильное приложение для вуза (демо)

## Цель проекта

Разработать прототип мобильного приложения для студентов и сотрудников вуза, который предоставляет быстрый доступ к расписанию занятий, актуальным новостям и позволяет формировать публичный профиль.

## Функционал

### Экран «Новости»
Приоритет разработки: низкий.
- Отображение новостей: автор, аудитория, категория, заголовок, текст, дата публикации, невидимый срок актуальности.
- Категории: «Образование», «Объявления», «Мероприятия», «Наука», «Спорт», «Без категории».
- **Свайп влево** — отметить новость как «прочитанную». Статус сохраняется локально.
- **Свайп вправо** — добавить новость в «Сохранённое». Список сохранённых хранится локально и доступен в профиле.
- **Тап по автору** — переход в его профиль.
Новости при запросе на сервер отпраляются все которые ещё актуальны, и на клиенте уже фильтруются те что были просмотренны.

### Экран «Расписание»
Приоритет разработки: высокий.
- Просмотр расписания по группе, преподавателю (базовый фильтр).
- Отображение события: день недели, время, предмет, аудитория, тип занятия (лекция, семинар, лабораторная работа, дополнительное мероприятие).
- Добавление и редактирование событий не реализовано в пользовательском интерфейсе.

### Экран «Профиль»
Приоритет разработки: высокий.
Просмотр и редактирование собственного профиля:
- Базовые: имя, фамилия, отчество, дата рождения, курс, направление подготовки, родной город.
- Аватарка в виде URL на сторонний хостинг.
- Навыки с уровнями владения.
- Интересы.
- О себе.
- Контакты.

---

Заделы на будующее:
- **Модерация публикаций.** В текущей версии публикация новостей доступна без модерации.
- **Таргетинг по аудиториям.** Присутствует возможность выбора аудитории всем, по факультетам, по группам.
- **Добавление событий в расписание.** Пользовательский интерфейс для не предусмотрен. Добавление событий на сервере непосредственно в базу данных.
- **Ролевая модель.** Реализована скорее визуальная логика разделения пользователей на студентов, преподавателей, сотрудников Университета.

## Стек технологий 

- Мобильное приложение: Android, Kotlin.
- Серверная часть: Node.js, Express.
- Хранение данных: файловое хранилище (JSON, csv).

---

## Принципы работы

- Клиент просто каждый раз запрашивает данные у сервера по REST‑интерфейсу. В будующем возможно будет добавлено кеширование на клиенте.

---

## Сценарии использования

1. **Просмотр новостей.** Пользователь открывает вкладку «Новости».
2. **Проверка расписания.** Пользователь видит расписание своей группы, изучает детали занятия (время, аудитория, тип).
3. **Работа с профилем.** Пользователь редактирует свой профиль, добавляет навыки и интересы.
