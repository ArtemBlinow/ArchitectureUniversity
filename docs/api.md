# API для демо‑прототипа мобильного приложения вуза

Базовый URL
http://<host>:<port>/api

# Авторизация
Для всех запросов, требующих идентификации пользователя, используется токен авторизации.

# Новости
Получение списка новостей
GET /news

Сервер просматривает все актуальные новости и фильтрует их по доступности пользователю.

Пример:
```
{
    "status": "ok",
    "data": [
        {
            "id": "news123",
            "title": "Хакатон по разработке бота для мессенджера MAX",
            "author": {
                "id": "user456",
                "fullName": "Платов Иван Иванович",
                "role": "преподаватель"
            },
            "category": "Event",
            "audience": "ПРИ23/1",
            "content": "Текст новости...",
            "publishedAt": "2026-11-03T10:00:00Z",
            "expiresAt": "2026-11-10T10:00:00Z"
        },

        {
            "id": "news124",
            "title": "Стажировка в Neoflex",
            "author": {
                "id": "user456",
                "fullName": "Родионов Иван Иванович",
                "role": "преподаватель"
            },
            "category": "Event",
            "audience": "ИИТ",
            "content": "Текст новости...",
            "publishedAt": "2026-11-03T10:00:00Z",
            "expiresAt": "2026-11-10T10:00:00Z"
        }
    ],
}
```
Несмотря на то что новость может быть для нескосльких "audience", сервер в ответе отправляет только один, наиболее подходящий пользователю.

# Обновление профиля
PATCH /profile

Тело запроса: любые поля из профиля, которые нужно обновить.

```
{
  "about": "Теперь ещё и бэкенд понемногу делаю.",
  "skills": [
    { "name": "Node.js", "level": "beginner" }
  ]
}
```

Ответы:

200 OK — профиль успешно обновлён.
Или сообщение об ошибке

# Расписание

Получение расписания
GET /schedule?group="ПРИ23/2"

```

    "data": [
        {
            "dayOfWeek": "вторник",
            "date": "2026-11-05",
            "startTime": "09:00",
            "endTime": "10:30",
            "subject": "Алгоритмы и структуры данных",
            "room": "307",

                "id": "user111",
                "fullName": "Петров Пётр Петрович"

```


# Ошибки

Сервер отправляет сообщение в следующем формате:

```
{
    "status": "error",
    "error": {
        "code": "INVALID_INPUT",
        "message": "Поле 'course' должно быть целым числом от 1 до 6."
    }
}
```
